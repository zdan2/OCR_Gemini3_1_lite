# おたより工房（ローカル版）

保育園のおたよりを作るツール。コンセプトを伝えると Claude が文章・イラスト・色・**段組みまで**決めて
A3横2ページに組み、画面で直してから PDF にする。

claude.ai の Artifact 版と違って、ここでは Claude API に直接つなぐ。
モデルも考える量もプロンプトも自分で決められる。

## つかう

```
cd C:\test\otayori
run.cmd
```

初回だけ `.venv` を作って `anthropic` を入れる。あとはブラウザが開く（http://127.0.0.1:8787）。
止めるのは Ctrl+C。

手で動かすなら:

```
C:\Python313\python.exe -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe server.py
```

## TrueNAS（Dockge）で動かす

`compose.yaml` と `Dockerfile` で、Tailscale 経由でだけ開けるコンテナとして動かせる。
手順は [TRUENAS.md](TRUENAS.md)。コンテナでは `OTAYORI_DATA` と `OTAYORI_ENV_FILE` で
控え・自作のイラスト・APIキーの置き場所を `/app/data` に向けている。

## APIキー

画面から設定できる。キーが無いまま開くと「AIにつなぐ」のウィンドウが出るので、
`sk-ant-` ではじまるキーを貼りつけて「つなぐ」を押す。あとから変えるときは、左上の接続表示を押す。

- 貼りつけたキーは、Anthropic に一度問い合わせて使えることを確かめてから `.env` に保存する。
- `.env` は .gitignore 済み。画面には末尾4文字しか返さない。
- 「キーを消す」で `.env` からキーの行だけを消す。

画面で設定しない場合は、次のどれかでもよい（画面で設定したキーがいちばん優先される）。

1. 環境変数 `ANTHROPIC_API_KEY`
2. `ant auth login` で作るプロファイル

画面の左上に「AIにつながっています」と出れば通っている。
キーが無くても、文字とイラストの編集・かざり・段組みの変更・印刷はできる。

キーはこのサーバのプロセスだけが持ち、ブラウザには渡していない。
ほかのサイトのページからこのサーバへの書きこみは断る（Origin を確かめている）。

## 紙面の作り

固定テンプレートではない。1ページは三層でできている。

```
top      … 全幅の帯（題字、ページ見出し、あいさつの吹き出し など）
columns  … 可変の段組み。1〜4本、幅は比で指定
bottom   … 全幅の帯（編集後記、イラストの帯 など）
```

ブロックの種類は15。text / list / schedule / pair / chips / lead / quiz / banner / note /
comments / photo / table / illband / head / title。
AIが毎号ちがう組み方を選ぶし、紙の上のボタンで足す・動かす・消すもできる。

囲みは paper（画用紙）/ balloon（吹き出し）/ frame（二重枠）/ band（色帯）/ plain（囲みなし）。
留め具はマスキングテープ2種と画鋲。イラストは72点から選ぶ。

## かざる

保育士さんが文字の設定を読まずに選べるよう、「② かざる」タブは全部見本つきのボタンにしてある。
押せばすぐ紙に反映され、上の「もどす」で戻せる。

| 項目 | 中身 |
|---|---|
| おまかせ | ふんいきを1つ選び、季節に合うイラストに入れかえる。押すたびに変わる |
| ふんいき | もよう・題字と見出しの書体・もりもり度・囲みのわく・テープ・かたむきをまとめて着せかえる（6種） |
| もりもり度 | ひかえめ / もりもり / てんこもり（`theme.level` の futsu / mori / max） |
| いろ・イラスト・もよう・文字 | それぞれ個別に変える。イラストは季節を押すたびに入れかわる |

ふんいきは `static/app.js` の `MOODS` に1件足せば増やせる。

紙の上の囲みにマウスをのせると「かざる」ボタンが出る。わく・とめるもの・かたむき・たかさを、その囲みだけ変えられる。
「たかさ」を「下までのばす」にすると、段の下のあまりまで囲みがのびる（`grow: true`）。
段の横幅は、段と段のあいだの ⇔ を左右にドラッグして変える（紙の上で 260px より細くはならない）。

## イラストを貼る

「② かざる」タブの「イラストを貼る」の一覧から、押すか紙の上へドラッグすると、好きな場所に貼れる。
貼った絵は、ドラッグで動かす・右下の●で大きさ・上の●でまわす・×（または Delete キー）ではがす。
ダブルクリックで別の絵にかえる。原稿では `pages[].stickers` に `{k, x, y, s, r}`
（x, y は紙の上の中心 px、s は一辺 px、r は回転の度）で入る。

位置は左上の px で書いている。`translate(-50%)` を使うと画像PDF（html2canvas）が読めないため。

## 自作のイラスト

「＋ 自分の絵を追加」で画像を取りこむ。一覧の上に画像ファイルをドラッグしてもよい。
白い紙に描いた絵をスマホで撮った写真をそのまま使えるよう、取りこむときに次をする。

- 長い辺を 600px に縮める
- 「白い背景を消す」がオンなら、白に近いところを透明にする（線のふちはなめらかに残す）
- まわりの透明な余白を切る

できた PNG は `data/illust/<id>.png`、名前は `data/illust/index.json` に入る。
一覧では「じぶんの絵」としていちばん上に出て、貼る絵にも、題字や見出しのイラスト欄にも使える。
キーは `u_<id>`。消すと、貼った絵は紙から消え、題字などに使っていた所は さくら になる。

## フッター

ページの下の端の「＋ フッターを足す」で、題字と同じく囲みに分かれていない1行を足せる。
ページごとに足すかどうかを選ぶ（`pages[].footer` に文字列。無ければ出さない）。
紙の上で直接書きかえる。Enter では改行しない。
消すときは、マウスをのせるとフッターの上に出る「× フッターを消す」を押すか、文字を全部消して欄の外を押す。
（消すボタンを右端に置くと、角のイラストの下に隠れて押せなくなるので真ん中に出している）
AIが住所や電話を作り話しないよう、文字は先生が入れる。

## 写真

入れ方は三つ。どれも長い辺 1400px の JPEG に縮めてから載せる（ブラウザの自動保存の容量に収めるため）。

- 紙の上の写真の枠を押す（空の枠には「クリックで写真をえらぶ」と出る。入っている写真を押すと差しかえ）
- 写真ファイルを紙の上へドラッグする（枠の上ならその枠へ、写真の囲みの上ならそこへ足す）
- 「② かざる」タブの「写真をのせる」

写真の囲みが紙になければ、いちばんすいている段に自動で作る。
写真が多くて自動保存に入りきらないときは、「⑤ ほぞん」タブで保存するよう知らせる。
紙の上のボタンは、紙を縮小表示していても画面上の大きさが変わらない（`--inv` で拡大を打ち消している）。

## プロンプトを直す

`prompts/` の4ファイルがそのまま AI への指示になる。保存すれば次のリクエストから効く。
サーバの再起動はいらない。

| ファイル | いつ使うか |
|---|---|
| `compose.txt` | コンセプトからおたより全体を組むとき |
| `revise.txt` | 「直してほしいこと」で直すとき |
| `comment.txt` | 子どもの様子の文章を作るとき |
| `chat.txt` | 最初のヒアリングの受け答え |

文体や禁則を園に合わせて書き換えるのが、いちばん効く直し方。

## イラストを足す

`static/illust.js` の `ILL` に1行足すだけ。

```js
newkey:['分類','表示名','<path d="…" fill="#e8615f"/>'],
```

viewBox は `0 0 48 48`。色は直接書く（CSS変数は使えない。PDFにするとき解決されないため）。
`SEASON_SETS` に入れると、季節の入れかえでも出るようになる。

## フォーム連携（光の原だより）

Googleフォーム「光の原だより 原稿提出」から、**区分ごとのいちばん新しい提出**を取り込んで紙面に流し込む。
左の「フォーム連携」タブから使う。

### はじめに1回だけ（フォームの持ち主のアカウントで）

1. フォームの編集画面 → 右上の︙ →「スクリプト エディタ」
2. `apps_script/Code.gs` の中身を全部貼り付ける。`KEY` を長いでたらめな文字列に変える
3. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：自分
   - アクセスできるユーザー：全員
4. 出てきた URL の末尾に `?key=（KEYと同じ文字列）` を付けて、「フォーム連携」タブの「取り込み先」に貼って「設定」

URL は `data/form_source.json` に保存される（git には入らない）。画面には key の中身を伏せて出す。

園の Google Workspace で「全員」を選べない設定になっていると、取り込みはログイン画面で止まる。
そのときは管理者に相談するか、下の CSV の方法を使う。

**別の方法：回答スプレッドシートを CSV で公開する。** フォームの「回答」タブ → スプレッドシートにリンク →
シートで「ファイル → 共有 → ウェブに公開」→ 回答のシートを選び「カンマ区切り（.csv）」→ その URL を貼る。
こちらは key が無いので、URL を知っている人なら誰でも原稿を読める。

### うごき

- 「最新を取り込む」で、区分ごとに新しい提出を1件ずつ取ってくる。「回答を編集」で出し直したものも新しい方として扱う。
- 「この内容で紙面を作る」で、光の原だより（A3横2ページ）を組む。1ページ目に園の5区分、2ページ目にクラス6つ。
  号数は、月の前半に作れば今月号、後半なら翌月号にする。色あいとイラストは季節で選ぶ。
- 組んだ紙面のブロックは、どの区分のどの提出から来たかを覚えている（編集中はブロックの上に「フォーム：保健から 11/8 09:30」と出る）。
  **新しい提出が来たブロックだけ**中身を差し替える。見出し・イラスト・囲み・段組みはそのまま。
  提出後に紙の上で直した文章は、その区分から次の提出が来るまで残る。
- 「自動で取り込む」を選ぶと、1分・5分・15分ごとに取り込む。画面を開いている間だけ動く。
- 「来月の予定」は「11日（月）山の日」のような行が多ければ日付のバッジ付きの予定表に、
  「園からのお願い」は行頭が「・」の行か「。」で終わる行が並んでいれば箇条書きにする。どちらでもなければ書かれたままの文章で載せる。
- 提出状況の表に、区分ごとの提出日時・字数／上限・状態（未提出／字数オーバー／前の号かも／未反映／反映済み／紙面になし）が出る。

### 字数とはみ出し

段に入りきらないときは、その段だけ文字を 0.5px ずつ小さくする（紙の上で 11px ≒ 印刷で 8pt まで）。
それでも入らない段は赤い破線で囲む（印刷には出ない）。

フォームの上限どおりに書けば収まる。試したときの文字の大きさ:

| 書いた量 | 1ページ目（3段） | 2ページ目（3段） |
|---|---|---|
| 各区分が上限いっぱい・クラスは全体で330字 | 12 / 11.5 / 13.5px | 11 / 11 / 11px |
| クラスが450字 | 同上 | はみ出す（赤い破線） |

クラスの記事は「ねらい」を枠で囲み、保育・食事・お知らせ・お願いは文頭にラベルを付けて続ける。
フォームの欄名がそのままラベルになるので、欄を足したり名前を変えたりしても動く。

全部で 579 点（工房で描いた 76 点 ＋ Fluent Emoji から選んだ 503 点）。ほかに、先生が足した「じぶんの絵」。

- **探す**：イラストを選ぶ小窓と「② かざる」の一覧の上に、検索欄と分類の絞り込みがある。
  ひらがなでもカタカナでも当たる（「パンダ」「ぱんだ」）。「工房の絵／Fluent の絵／じぶんの絵」でも絞れる。
  最近使った 16 点は「さいきんつかった」にいちばん上に出る（この端末のブラウザに残る）。
- **AIに描いてもらう**：「② かざる」の「イラストを貼る」で、「玉入れをするこども」のように頼むと 3 案描く。
  「使う」を押した案は PNG にして「じぶんの絵」に入る。工房の絵柄に合わせる決まりは `prompts/draw.txt`。
  AI が返した SVG は、サーバで図形と塗りだけに組み直してから画面に出す（スクリプトや外への参照は残さない）。
  1 回ごとに API の料金がかかる。

### Fluent Emoji について

Microsoft の [Fluent Emoji](https://github.com/microsoft/fluentui-emoji)（Flat 版）から、保育園のおたよりで
使いそうなものを選んで日本語の名前と分類を付けた。MIT License。許諾文は `static/fluent-LICENSE.txt`。

**おたよりの紙面にライセンスを載せる必要はない。** MIT License が求めるのは、SVG のファイルそのものを
複製・配布するときに許諾文を添えること。工房に同梱しているので、工房（git・TrueNAS など）に許諾文を置いている。

絵を足したり名前を変えたりするときは、`tools/fluent/pick.txt` を書きかえて組み立て直す。

```
cd tools\fluent
python build_fluent.py
```

`static/illust_fluent.js` が作り直される。書き方は `フォルダ名|日本語の名前|分類`。
フォルダ名は https://github.com/microsoft/fluentui-emoji/tree/main/assets の名前。

## 出力

- **印刷 / PDF** … ブラウザの印刷から「PDFに保存」。文字が選べる・検索できるPDFになる。
  余白は「なし」、背景グラフィックは「オン」にすること。きれいなのはこちら。
- **画像PDFで保存** … 紙面を画像にしてPDFにする。ワンクリック。文字は選べない。

## 控え

「⑤ ほぞん」タブから `data/<名前>.json` に保存・読み込みできる。
来月はこれを読み込んで直すのがはやい。
ブラウザ側にも自動で下書きが残る（この端末のこのブラウザだけ）。

## ファイル

```
server.py          静的ファイル配布 + Claude API の中継
prompts/*.txt      AIへの指示。編集可
static/illust.js   イラスト72点・季節セット・色あい7種
static/render.js   自由レイアウトの組版
static/app.js      画面の操作とサーバとのやりとり
static/style.css   画面と紙面のスタイル（印刷用も）
data/*.json        おたよりの控え
```

## 既定のモデル

`claude-opus-5-5`。「⑤ ほぞん」タブの「AIのくわしい設定」で Sonnet 5.5 / Haiku 5.5 / Fable 5.1 に変えられる。
「考える量」は effort（low〜max）。段組みまで考えさせるので high 以上をすすめる。
