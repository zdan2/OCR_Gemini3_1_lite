保育園のおたよりに貼る、小さなイラストを SVG で描きます。
このファイルは編集できます。園の好みの色や描き方に合わせて書き換えると、次から効きます。

# 描くもの
<<WHAT>>

# 描き方（工房のほかの絵とそろえる）
- 画面は viewBox="0 0 48 48"。絵は 4〜44 の範囲いっぱいに、まんなかに大きく描く。
- かたちは、まる・だえん・角の丸い四角・やわらかい曲線でつくる。こまかい線や小さすぎる部品は入れない（印刷で 2cm くらいに小さくなっても、何の絵かわかるように）。
- 色はべた塗りだけ。グラデーション・影・ぼかし・文字は使わない。輪郭線は使わないか、使うなら 1.5〜2.5 の太さで色はこげ茶 #5a4330 か紺 #3d4652。
- 色は次の中から 3〜6 色を選ぶ：
  #e8615f あか / #f3a0b4 ピンク / #f0974a オレンジ / #f5c646 きいろ / #78b65a きみどり / #4f8f49 みどり /
  #5b9bd5 みずいろ / #44689e あお / #9b85c4 むらさき / #a9774a ちゃいろ / #7a5434 こげちゃ /
  #fdf3df クリーム / #fbd9bd はだいろ / #3d4652 こん / #ffffff しろ
- 顔があるものは、目を小さな黒い点（r=1.6〜2.2）、口をみじかい曲線にして、ほっぺにうすいピンクのまるを置く。こわい顔・リアルな顔にしない。
- 人を描くときは、2〜3頭身のこども向けのかわいい絵にする。
- 使ってよい要素は g・path・circle・ellipse・rect・line・polyline・polygon だけ。要素は全部で 40 個まで。

# 返すJSON（これだけを返す）
{"svgs":["<svg xmlns=\"http://www.w3.org/2000/svg\" viewBox=\"0 0 48 48\">…</svg>", "…", "…"]}

- 3案。案ごとに、ポーズや向き・色の組み合わせを変える。
- JSON の文字列の中なので、" は \" と書く。
