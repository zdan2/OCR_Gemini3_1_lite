# 返し方
- 同じキー構成のJSON全体を返す。前後に説明を書かない。
- 指示に関係ない部分は、いまの文章・イラスト・段組みをそのまま残す。
- 段組みや ブロックの並べ替え・追加・削除をしてよい。レイアウトの指示なら columns の数や w を変える。
- comments ブロックの items は、先生が入れた文なので消さない。
- photo ブロックの items も消さない（写真が入っている）。
- pages[].stickers（先生が好きな所に貼ったイラスト）は、指示がなければ位置も大きさもそのまま残す。
- 「u_」ではじまるイラストのキーは先生が描いた絵。消したり、ほかのキーに置きかえたりしない。
- pages[].footer（ページ下の1行。園の住所や電話など）は先生が入れたものなので、指示がなければそのまま残す。無いページに勝手に足さない。
- ブロックにある src と srcTime は、フォームの提出とつながっている印。値を変えず、そのブロックに付けたまま残す。
  ブロックの種類を変えたり、ほかの段へ動かしたりしても、src と srcTime はそのブロックから外さない。
  ほかのブロックに付けかえたり、新しく足したブロックに付けたりはしない。

# ブロックの種類（kind）と、それぞれの形
新しく足すブロックも、書きかえるブロックも、必ずこの形で書く。items の中身の形（文字か、{…}か）をまちがえると紙面に何も出ない。
{"kind":"title","ill":"絵","illR":"絵","title":"題字","sub":"副題"}
{"kind":"head","ill":"絵","text":"2ページ目の見出し"}
{"kind":"lead","ill":"絵","heading":"見出し","body":"あいさつ文"}
{"kind":"text","ill":"絵","heading":"見出し","body":"本文"}
{"kind":"section","ill":"絵","heading":"見出し","parts":[{"k":"ラベル","v":"文章"}, …]}   ← クラスのたよりなど。k（「ねらい」「様子」）は先生の区切りなので、指示がなければ変えない
{"kind":"list","ill":"絵","heading":"見出し","items":["文", …]}
{"kind":"schedule","ill":"絵","heading":"◯月の予定","items":[{"date":"12/5","label":"運動会"}, …]}   ← 行事の予定はこれ。日にちがまだなら date は ""
{"kind":"pair","ill":"絵","heading":"見出し","items":[{"k":"うた","v":"曲名"}, …]}
{"kind":"chips","ill":"絵","heading":"おたんじょうびおめでとう","items":[{"name":"名前","note":"12/3"}, …]}   ← 丸いふだを並べる。items は必ず {"name","note"}
{"kind":"quiz","ill":"絵","heading":"見出し","q":"問い","a":"こたえ"}
{"kind":"banner","ill":"絵","text":"一行のおしらせ"}
{"kind":"note","ill":"絵","heading":"編集後記","body":"文"}
{"kind":"comments","ill":"絵","heading":"こどもたちのすがた","cols":3,"items":[…]}
{"kind":"photo","heading":"見出し","items":[{"caption":"写真のせつめい"}, …]}
{"kind":"table","ill":"絵","heading":"見出し","head":["列1","列2"],"rows":[["",""], …]}
{"kind":"illband","items":["絵", …]}
任意: box（paper/balloon/frame/plain/band）、tape（tape/taper/pin/none）、tilt（-1.5〜1.5）、bg（見出しの色。いまの値を残す）

# 文章の決まり
- ていねいだが固すぎない「です・ます」調。
- どの本文にも子どもの具体的な動きをひとつ入れる。
- 絵文字、顔文字、！の連続、号令口調、評価の言葉（上手、えらい、一番）は使わない。
